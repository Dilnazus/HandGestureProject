# A deep learning project for recognizing hand gestures in real time.

## Planned features
-Сбор видеоданных
- Извлечение точек на руках
- Классификация жестов с помощью модели LSTM
- Распознавание в реальном времени через вебкамеру

## Technologies

- Python
- OpenCV
- MediaPipe
- TensorFlow
- NumPy
- scikit-learn
